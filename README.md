# 🐍 Python Basics (Computer Science)

This repository contains a collection of Python scripts and exercises developed for the **Computer Science** course at **Politecnico di Torino** (Academic Year 2024-2025). 

The course is part of the **Management Engineering (L-8)** curriculum. These projects focus on core programming fundamentals, including:
* **Logic & Control Flow:** Conditional statements and loops.
* **Data Structures:** Advanced usage of lists, tuples, and dictionaries.
* **File I/O Operations:** Reading, parsing, and writing text files.
* **Basic Algorithm Design:** Applied to real-world business and data scenarios.

> 💡 **Language Note:** While this README and the repository structure are in English to be accessible to an international audience, the actual source code (`main.py`), variables, internal comments, and the original assignment traces (`README.md` inside each folder) remain in Italian to align with the original university datasets and exam requirements.

## 📂 Projects & Scripts Overview

Each folder acts as a standalone mini-project containing the main Python script (`.py`), the original assignment trace (`README.md`), and the necessary dataset text files (`.txt`).

* **[Australian Open](./australian-open):** Data processing and statistics calculation for tennis tournament matches.
* **[Beach Club](./beach-club):** Management script for beach umbrella bookings and facility services.
* **[Bowling](./bowling):** Score calculation and player ranking system for bowling games.
* **[Degree Requirements](./degree_requirements):** Evaluation tool for university credit checks and graduation criteria.
* **[Dinosaurs](./dinosaurs):** Simulation of a two-player dinosaur-themed card game based on deck generation and game logic.
* **[Dog Shelter Database](./dogshelter-database):** Inventory and adoption management for an animal shelter.
* **[E-Commerce](./e-commerce):** Analysis of online store transactions, customer logs and sales metrics.
* **[Glucometer](./glucometer):** Processing and anomaly detection in patient blood sugar readings.
* **[Hacking](./hacking):** Log analysis for detecting unauthorized access or cybersecurity events.
* **[Highway Tolls](./highway-tolls):** Calculator for highway toll fees based on vehicle types and distance.
* **[Libraries](./libraries):** Management of book loans, returns and library inventory.
* **[Open Access](./open-access):** Analytics script for academic publications and open-access data.
* **[Painting](./painting):** Text-based image composition tool that merges smaller pixel-art files into a single main canvas.
* **[PC Loan](./pc-loan):** Tracking system for university/company computer equipment loans.
* **[Plane Passengers](./plane-passengers):** Processing of airline passenger manifests and flight data.
* **[Post Office](./post-office):** Queue management and package tracking logic for postal services.
* **[Price Basket](./price-basket):** Computation of inflation and price variations across a consumer goods basket.
* **[Restaurant Bill](./restaurant-bill):** Script for managing table orders and calculating total bills.
* **[Sleigh Ride](./sleigh-ride):** Route optimization to manage and track gift deliveries.
* **[Social Popularity](./social-popularity):** Engagement metrics analysis for social media interactions.
* **[Students Database](./students-database):** Processing of university student records and academic performance.
* **[Tales Characters](./tales-characters):** Text analysis script focusing on characters from stories or books.
